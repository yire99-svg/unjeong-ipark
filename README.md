# 운정신도시아이파크 34평 매물

GTX-A 운정중앙역 인근 운정신도시아이파크(파주 동패동) 전용 84㎡ 매물 현황 페이지.
네이버페이 부동산 매물을 수집해 정적 HTML로 만듭니다.

## 갱신하기

```sh
./refresh.sh
```

`build.mjs`가 로컬 MCP 서버(`~/mcp-realestate/index.js`)를 통해 최신 매물을 받아
`index.html`을 다시 만들고, 변경이 있으면 커밋·푸시합니다. 푸시하면 GitHub Pages가
1~2분 안에 반영합니다.

빌드만 하려면:

```sh
node build.mjs
```

## 구성

| 파일 | 역할 |
|---|---|
| `build.mjs` | 매물 수집 → `index.html` + `data.json` 생성 |
| `refresh.sh` | 빌드 + 커밋 + 푸시 |
| `shot.mjs` | 라이트/다크/모바일 스크린샷 (검수용) |
| `index.html` | 배포되는 페이지 (생성물) |
| `data.json` | 같은 데이터의 원본 JSON (생성물) |

## 주의

- 호가는 매도 희망가이며 실거래가가 아닙니다.
- 같은 집이 여러 중개사에 중복 등록될 수 있습니다.
- 방·조건·옵션은 중개사 매물 설명에서 자동 추출한 값이라 누락이 있을 수 있습니다.
- 수집이 0건이면 `build.mjs`가 종료 코드 1로 실패하므로, 빈 페이지가 배포되지 않습니다.
